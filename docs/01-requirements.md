# 需求

输入素材与发布时间要求，Agent 逐项审核、补查、处理时段冲突，生成待用户确认的排期草稿。只保存草稿，没有发布能力。完整标准保留于 spec/。

| 验收点 | 要求 | 场景 |
|---|---|---|
| A1 | 审核通过、时段空闲时按要求排期 | S01 |
| A2 | 信息缺失先补查，仍缺则 need_info，不排期 | S02 |
| A3 | 区分阻断、需确认、需补查 | S03 |
| A4 | flexible 在约束内给替代并请求确认；fixed 冲突不改时段 | S04、S05 |
| A5 | 同一请求一份草稿，相同内容 duplicate，业务变化 updated | S06、S06b |
| A6 | 保存失败如实报错，文件不改变 | S07 |

额外覆盖工具重试、步数与调用次数限制、第二轮用户确认。最终逐项输出审核状态、风险、建议时段、确认事项和保存状态，自动检查 I1–I7。

硬约束包括 fixed 时间、日期、渠道、时间范围与素材禁发期；模型不得自行确认。保存状态只来自真实工具记录，本次未经检查的素材不能伪装成已审核素材保存。
